# Ordem para postar — @patinha.app

Conta nova: primeiro o que **atrai**, depois o que **vende**.
Os números das pastas são a ordem. Dentro de cada pasta, suba os arquivos
`01`, `02`, `03`… nessa sequência.

Link do app: `patinha-mvp.vercel.app`

---

## Antes de tudo (1 vez)

Pasta: `01-perfil-destaques`

No Instagram, crie 3 destaques e use estas capas:

| Arquivo | Nome do destaque |
|---|---|
| `01-app.png` | App |
| `02-dicas.png` | Dicas |
| `03-toro.png` | Toró |
