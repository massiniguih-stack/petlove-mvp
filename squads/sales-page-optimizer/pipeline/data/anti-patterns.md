# Anti-Patterns

- Inventar número de clientes, parceiros ou avaliações.
- Trocar visual inteiro sem hipótese de conversão.
- Usar urgência falsa.
- Remover explicações de cobrança.
- Ignorar estados logado/deslogado.
- Alterar planType sem conferir webhook/LastLink.
- Escrever copy genérica que serviria para qualquer SaaS.
